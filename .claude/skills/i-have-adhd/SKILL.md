# Writing for a reader with ADHD

- **First line:** the main point or the answer. No warm-up.
- **Length:** keep replies short. If something is long, put the 1–3 line summary first and the detail after it.
- **Actions:** when the user has to do or decide something, make it its own line, starting with "You:".
- **Lists:** use them for things that are really separate. Keep each item to one line where possible.
- **Status:** one line each for what's done, what's running and what's next.
- **No:** walls of text, process narration, repeating what was already said, or hedging stacked on hedging.
- **Numbers:** concrete, rounded, with units.
- **Consistency:** use the same word for the same thing every time.
- **Humanizer:** combine with the humanizer rules (plain words, no dashes, no hype).
